The first release of PaperKnife for Mac: edit the text of your PDFs on your Mac, offline.

## What it does

- **Edit text in place.** Click any text to select its line or table cell, type, and press
  Return. PaperKnife keeps the original font, size, position and color, and changes only the
  characters you changed.
- **Verified edits.** After every edit PaperKnife reads the result again and compares the whole
  page; if anything else would change, it refuses the edit and says why, instead of damaging the
  document.
- **Hard PDFs too.** PDFs that draw every letter on its own (a click selects the whole line, not
  one letter), PDFs saved from browsers, and LaTeX PDFs, where PaperKnife can even add letters
  the PDF's fonts didn't contain.
- **Pages.** Rotate, delete and add pages from another PDF. Undo and redo, and Save As.
- **Private.** No uploads, no account, no telemetry: PaperKnife has no networking code.

PaperKnife for Mac runs the engine of
[PaperKnife for Windows 0.5.1](https://github.com/shivam098/paperknife-windows/releases/tag/v0.5.1),
ported line by line, and passes the same 128 conformance tests, so it edits the same PDFs the
same way.

## Which file do I need?

| File | Choose it if |
|---|---|
| `PaperKnife-0.5.1-mac.dmg` | **Most people.** Open it and drag PaperKnife to Applications. |
| `PaperKnife-0.5.1-mac.zip` | You'd rather unzip the app. |
| `SHA256SUMS.txt` | Checksums of the files above (`shasum -a 256 <file>`). |

One app for Apple silicon and Intel Macs, with macOS 13 (Ventura) or later.

**This release isn't signed with an Apple Developer ID yet**, so the first time you open
PaperKnife, macOS says it can't check it for malicious software. To open it anyway, once:

- on macOS 15 (Sequoia) or later, try to open it, then go to **System Settings > Privacy &
  Security** and select **Open Anyway**;
- on macOS 13 or 14, Control-click PaperKnife in Applications, choose **Open**, then **Open**.

## Known limits

PaperKnife refuses an edit rather than damage your document. In this version it can't:

- add characters that the PDF's font doesn't contain, except in LaTeX's Computer Modern, Latin
  Modern and CM-Super fonts (with the limits the
  [Windows release notes](https://github.com/shivam098/paperknife-windows/releases/tag/v0.5.1)
  describe);
- keep centered text centered: the edited text starts where the old text started;
- edit some pages of encrypted PDFs, which are edited by rewriting the whole page;
- edit a line as one piece when the PDF splits it across fonts, for example the "fi" in
  "Confirmed" in PDFs saved from Chrome; each piece can be edited on its own;
- edit scripts that need text shaping (such as Hindi or Arabic), add line breaks, or edit scanned
  pages;
- reorder, extract or merge pages yet.

PaperKnife for Mac isn't sandboxed yet; the App Sandbox without network access is planned
together with notarization (see the
[roadmap](https://github.com/shivam098/paperknife-macos/blob/main/docs/ROADMAP.md)).

This is an early preview: keep a backup of any document you can't afford to lose, and please
[report problems](https://github.com/shivam098/paperknife-macos/issues).
