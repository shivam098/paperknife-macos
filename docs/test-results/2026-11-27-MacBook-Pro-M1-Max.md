## Build and CI checks on the host

PDFium chromium/8152 passed the pinned SHA-256 check; its dylib contains arm64 and x86_64. `swift build` finished in 9.45 s, with the documented non-Sendable capture warning at `EditorModel.swift:225`. XCTest executed **62 tests, 0 failures**, in 93.070 s; `swift test` wall time was 106.32 s. `Conformance corpus: 128 of 128 cases give the stored observations.` The many-names step took **632 ms** (limit 3000 ms). Swift Testing separately reported zero tests; these tests use XCTest.

The universal `0.0.0-dev` package passed self-check. Both generated archives matched `SHA256SUMS.txt`; the DMG and unzipped app each passed strict signature verification and `--self-check` on **both** arm64 and translated x86_64. On a clean launch of the unzipped app, CI's scripts selected “Hello World” and reported “Text updated”. The field contained exactly “Hello PaperKnife”, and the edit was discarded. Initial attempts with foreground/focus changes did not give a clean result. The successful run checked click ownership and restricted the scripts' screenshots to the corpus document window.
