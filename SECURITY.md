# Security policy

PaperKnife opens files from untrusted sources, so security reports are very welcome.

Please **don't open a public issue.** Use GitHub's private vulnerability reporting: open the
repository's **Security** tab and select **Report a vulnerability**. If a sample file is needed,
share a minimal one that contains no personal information.

This repository doesn't contain app code yet; the current implementation is
[PaperKnife for Windows](https://github.com/shivam098/paperknife-windows).
